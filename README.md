## 简介

Cheems翻译是一款 Windows 桌面翻译软件，可自动识别输入内容并显示翻译浮层，支持 OpenAI 兼容模型和语音播报。

- 🌐 自动监控输入内容，实时显示翻译结果
- 🤖 支持 OpenAI 兼容接口，可连接本地模型
- 🔊 支持语音播报和手动朗读译文
