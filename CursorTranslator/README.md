# Cheems翻译

Windows 桌面翻译浮层，UI 使用 Avalonia，翻译 API 使用 OpenAI Chat Completions 兼容接口。

## 启动

需要 .NET 10 SDK：

```powershell
dotnet run --project .\CursorTranslator\CursorTranslator.csproj
```

程序使用单实例运行。启动后默认开启全局输入监控；普通启动时窗口隐藏到系统托盘。关闭设置窗口只会隐藏窗口，监控会继续运行，直到从托盘菜单选择“退出”。设置页可启用随 Windows 用户登录启动。

API 地址、模型名称、可选 API Key、系统提示词及翻译设置会在输入或选项更改后自动保存。API Key 可留空；非空时使用 Bearer 认证，并通过 Windows DPAPI 加密保存。默认启用文字变化模式，检测到输入变化就立即翻译；此模式会关闭句末和停顿选项。也可切换到句末或停顿触发，停顿秒数支持输入小数，范围为 0.5 到 60 秒。还可设置单次翻译上限（默认 10，范围 5 到 1000）：中文字符各计 1，英文单词计 1，标点和空白不计；超限时会在末尾附近寻找标点边界，尽量保留完整句子；试译不受此限制。系统提示词默认要求中译英，用户可以改成其他目标语言或指定翻译风格。待译内容会作为 JSON 数据单独传入，模型必须把其中的指令和问题当作原文翻译，而不能照做或回答。API Key 使用 Windows DPAPI 按当前用户加密后保存在 `%LocalAppData%\CursorTranslator\settings.json`。

AI 接入设置还可单独配置“深度分析指令”。默认指令会按顺序分析句中的关键词、短语及其语境义，并说明词语选择和近义表达的差异。译文旁的详解按钮会把完整译文提交给 AI，并在翻译浮窗内展开显示结果；只有 AI 接入且 AI 地址、模型和分析指令均已配置时可用，HTTP 翻译模式会禁用详解。

语音模型使用独立的 OpenAI 兼容文字转语音接口，填写 API 地址、模型、音色和可选 API Key。API Key 使用 Windows DPAPI 加密保存。开启“实时语音”后，监控翻译和手动试译都会自动播报；浮层喇叭按钮也可随时重播当前译文。开始新的播报时，先前音频会停止并被替换。

程序通过 WinEvent 监听前台应用报告的焦点、可访问对象值和名称变化，并在收到事件时立即重新读取；同时保留 180 毫秒定时读取作为兜底。文本读取依次尝试 UI Automation、Win32 Edit、MSAA 等系统文本接口。对于不提供 UI Automation 文本的 Word 兼容文档编辑器，会在文档窗口处于前台且正文获得焦点时，通过 Word 自动化接口优先读取当前选区；没有选区时读取光标所在段落，只在内容发生变化后提交。

部分框架会把输入框报告为 Custom、Group 或 Pane 等通用控件类型。监控只在多项证据同时成立时读取这类焦点控件：控件本身持有键盘焦点且可用，提供可写的 Value 或 TextEdit 接口，MSAA 角色不是静态文本、状态不是只读，并且系统光标、MSAA 光标或 UIA TextPattern2 光标位于控件内。Text、Button、ListItem 等类型一律不读取。满足条件的控件先进入观察期：已有内容不翻译，只有文本在用户输入后 1.5 秒内发生变化才确认为输入框；文本在没有输入时自行变化的控件会被判定为非输入框，本次运行内不再读取。输入法组字通过 UIA TextEditPattern 的活动组字区检测，等候选字上屏后再翻译。UIA3 请求设有 1 秒超时，避免目标程序无响应时拖住监控线程。

首次聚焦普通输入框时，输入变化模式会立即提交已有内容；句末模式会提交以标点结尾的内容；启用延迟模式后，无句末标点且达到指定停顿时长也会提交。后续输入按所选时机提交。最多翻译上限默认为 10，可设置为 5 到 1000；中文字符各计 1，英文单词计 1，标点和空白不计。超限时先在设置值上下 10 个计数单位范围内寻找标点边界，优先向后保留完整句子，再尝试向前截取，找不到时按设置值截取。空输入和能识别出的占位提示不会翻译，清空输入时浮层隐藏。密码框会跳过，监控文本不会写入文件。

浮层只显示完整成功的译文。首次翻译完成前保持隐藏；后续翻译期间保留上一条完整译文，只有新译文完整返回后才替换。模型输出达到长度上限时会报告错误，不显示被截断的译文。

托盘菜单的“翻译”会打开双栏翻译窗口（也可用 `--show-translator` 启动参数直接打开）。窗口使用当前选择的 AI 接口或 HTTP 翻译档案，但语种由窗口自己选择，不受监控用的翻译提示词影响：原文语种可选“自动检测”，译文语种可选“自动（中文 ⇄ 英语）”，即中文译为英语、其他语种译为中文；明确选择原文语种时按所选语种判断，未选择时在本地按文字判断（含假名或谚文的不算中文）。AI 接口会收到包含语种对的翻译指令；HTTP 档案的 `{{sourceLanguage}}` / `{{targetLanguage}}` 会填入 zh、zh-TW、en、ja、ko 等标准代码，接口使用其他代码时可在档案的“翻译窗口语种代码映射”中填写，如 `zh-TW=cht, ja=jp`（小牛翻译预设已包含 `zh-TW=cht`）。窗口支持输入停顿后自动翻译、Ctrl+Enter 立即翻译、交换语种（译文成为新的原文）、复制和朗读译文；语种与自动翻译开关会被记住，翻译不受单次翻译上限限制，并计入每日统计。

某些应用不向系统文本接口暴露输入内容，自动监控在这些输入框里仍不会生效。当前版只显示译文，不会把译文粘贴或写回原输入框。

为避免 Chromium/Edge 的 UIA 文档属性查询导致浏览器卡死，监控优先直接读取焦点输入框，浏览器窗口不扫描无障碍子树，所有应用均不对整页 Document 文本查询只读属性或读取全文。Document 控件只有提供可写 ValuePattern 时才作为输入框读取；Word 兼容编辑器继续使用文档段落接口。仅提供 Document TextPattern 的编辑器可能无法自动监控，可使用“复制后翻译”。Edit 控件的只读属性只查询一个插入点，UIA 输入文本最多读取 100,000 字符，超限时跳过该次读取。密集 WinEvent 会合并处理，UIA 轮询起点至少间隔 180 毫秒。

Chromium/Electron 窗口若未暴露文本，可查看监控状态，并按对应应用说明启用无障碍支持，或使用“复制后翻译”。

## 输入监控回归验证

运行 `dotnet run --project tests/InputMonitor.Regression/InputMonitor.Regression.csproj`（从仓库根目录执行）。测试在独立进程内提供真实 UIA 控件，验证文档不会进入 TextPattern 整页查询、可写输入框仍可读取，以及密码、只读、空值和超长文本处理；另外覆盖通用类型控件的证据判定（无光标、光标在控件外、只读、密码、静态文本和按钮类型均不读取）和观察期（已有内容不翻译、无输入时变化的控件被拒绝）。测试不需要翻译 API，也不会启动程序的全局监控。

## 更新安装交接

更新助手就绪后程序才会关闭，并先保存设置。助手最多等待 10 秒让旧进程正常退出；超时后只清理启动更新时记录且路径、PID、启动时间均匹配的本程序进程，避免残留进程让更新无限等待。同一安装目录只允许一个更新助手执行安装。安装失败时保留下载包并尝试重新打开程序。

交接日志保存在 `%LocalAppData%\CursorTranslator\Updates\update-install.log`，安装器详细日志保存在同目录的 `update-setup.log`。助手只等待安装器本身退出，避免被安装器启动的新程序拖住。

运行 `dotnet run --project tests/UpdateHandoff.Regression/UpdateHandoff.Regression.csproj -c Release` 验证更新交接。测试使用独立的模拟进程和安装器，在临时目录覆盖退出超时、正常退出、进程身份不匹配、安装失败回退及重复更新；不会修改本机已安装的 Cheems翻译。
