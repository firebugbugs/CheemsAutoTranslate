# Cheems翻译

Windows 桌面翻译浮层，UI 使用 Avalonia，翻译 API 使用 OpenAI Chat Completions 兼容接口。

## 启动

需要 .NET 10 SDK：

```powershell
dotnet run --project .\CursorTranslator\CursorTranslator.csproj
```

程序使用单实例运行。启动后默认开启全局输入监控；普通启动时窗口隐藏到系统托盘。关闭设置窗口只会隐藏窗口，监控会继续运行，直到从托盘菜单选择“退出”。设置页可启用随 Windows 用户登录启动。

API 地址、模型名称、可选 API Key、系统提示词及翻译设置会在输入或选项更改后自动保存。API Key 可留空；非空时使用 Bearer 认证，并通过 Windows DPAPI 加密保存。默认启用文字变化模式，检测到输入变化就立即翻译；此模式会关闭句末和停顿选项。也可切换到句末或停顿触发，停顿秒数支持输入小数，范围为 0.5 到 60 秒。还可设置单次翻译字数上限（默认 10 字，范围 5 到 1000）；超限时会在末尾附近寻找标点边界，尽量保留完整句子；试译不受此限制。系统提示词默认要求中译英，用户可以改成其他目标语言或指定翻译风格。待译内容会作为 JSON 数据单独传入，模型必须把其中的指令和问题当作原文翻译，而不能照做或回答。API Key 使用 Windows DPAPI 按当前用户加密后保存在 `%LocalAppData%\CursorTranslator\settings.json`。

语音模型使用独立的 OpenAI 兼容文字转语音接口，填写 API 地址、模型、音色和可选 API Key。API Key 使用 Windows DPAPI 加密保存。开启“实时语音”后，监控翻译和手动试译都会自动播报；浮层喇叭按钮也可随时重播当前译文。开始新的播报时，先前音频会停止并被替换。

程序每 180 毫秒读取当前焦点控件的 UI Automation 文本。首次聚焦时，输入变化模式会立即提交已有内容；句末模式会提交以标点结尾的内容；启用延迟模式后，无句末标点且达到指定停顿时长也会提交。后续输入按所选时机提交。最多翻译字数默认为 10，可设置为 5 到 1000；超限时先在设置值上下 10 字范围内寻找标点边界，优先向后保留完整句子，再尝试向前截断，找不到时按设置值截取。空输入和能识别出的占位提示不会翻译，清空输入时浮层隐藏。密码框会跳过，监控文本不会写入文件。

浮层只显示完整成功的译文。首次翻译完成前保持隐藏；后续翻译期间保留上一条完整译文，只有新译文完整返回后才替换。模型输出达到长度上限时会报告错误，不显示被截断的译文。

某些应用不向 UI Automation 暴露输入内容或光标矩形，自动监控在这些输入框里不会生效。当前版只显示译文，不会把译文粘贴或写回原输入框。
