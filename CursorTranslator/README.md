# 光标翻译（第一版）

Windows 桌面翻译浮层，UI 使用 Avalonia，翻译 API 使用 OpenAI Chat Completions 兼容接口。

## 启动

需要 .NET 10 SDK：

```powershell
dotnet run --project .\CursorTranslator\CursorTranslator.csproj
```

程序使用单实例运行。启动后默认隐藏到系统托盘并开启全局输入监听；双击托盘图标或选择“打开设置”显示窗口。关闭设置窗口只会隐藏到托盘，托盘菜单可暂停/恢复监听或退出程序。

在窗口填写 API 地址、模型名称、API Key 和系统提示词，然后点“保存连接设置”。系统提示词默认要求中译英，用户可以改成其他目标语言或指定翻译风格。待译内容会作为 JSON 数据单独传入，模型必须把其中的指令和问题当作原文翻译，而不能照做或回答。API Key 使用 Windows DPAPI 按当前用户加密后保存在 `%LocalAppData%\CursorTranslator\settings.json`。

点“开始监控”后，程序每 180 毫秒读取当前焦点控件的 UI Automation 文本。首次聚焦时若输入框已有内容会立即提交；后续输入在句末标点或停顿 850 毫秒后提交。每次都翻译输入框的完整当前内容，而不是只翻译最新一句。空输入和能识别出的占位提示不会翻译，清空输入时浮层隐藏。`Ctrl+Shift+Space` 可暂停或恢复。密码框会跳过，监控文本不会写入文件。

浮层只显示完整成功的译文。首次翻译完成前保持隐藏；后续翻译期间保留上一条完整译文，只有新译文完整返回后才替换。模型输出达到长度上限时会报告错误，不显示被截断的译文。

某些应用不向 UI Automation 暴露输入内容或光标矩形，自动监控在这些输入框里不会生效。当前版只显示译文，不会把译文粘贴或写回原输入框。
