# Cheems翻译 v0.0.5

Windows x64 正式版。

- 修复在 AliMail 等 Chromium/Electron 应用中，无障碍诊断扫描可能阻塞输入监控线程，导致切换到记事本后也无法触发自动翻译的问题。
- 优先直接读取焦点输入框，跳过浏览器无障碍子树扫描和整页 Document 文本查询，减少监控卡顿。
- 限制 UI Automation 文本读取长度，并合并密集事件，避免监控轮询过于频繁。
- 增加 11 项跨进程 UI Automation 回归验证，覆盖普通输入框、文档、密码、只读、空值和超长文本。

下载并运行 `CheemsTranslator-v0.0.5-Setup.exe` 即可升级，安装包包含 .NET 运行时。

未提供可读文本接口的输入框仍可使用“复制后翻译”。Android 版维持 v0.0.4。
